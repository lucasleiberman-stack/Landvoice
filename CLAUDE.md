# Landvoice homepage

Static homepage prototype (plain HTML/CSS/JS, no build tooling) that will later be lifted into WordPress as theme template parts. `README.md` has the full conventions, JS hook table, WordPress steps and the list of unfilled placeholders; read it before larger changes.

@STATUS.md

## Keeping context small (follow every session)
- Never read all of `index.html`. Grep for the section's `<!-- ===== NAME` comment and read only that range (offset/limit). `/section <name>` does this.
- Don't read `dist/` or `assets/img/` (denied in `.claude/settings.json`). Edit source files, then run `./bundle.sh`.
- One section or task per session. At the end run `/wrap` (updates `STATUS.md`, commits, no push).

## Layout
- `index.html`: the whole page (~570 lines). Each section is wrapped in a `<!-- ===== NAME (WP: template-parts/x.php) ===== -->` comment; find a section by grepping for that comment.
- `assets/css/00-tokens.css` (all colours/fonts/sizes), `01-base`, `02-layout`, `03-components`, plus one file per section in `assets/css/sections/`.
- `assets/js/NN-name.js`: small modules in load order, wired to the page only via `data-lv-*` attributes.
- `assets/img/`: images and SVGs.
- `dist/lv.css`, `dist/lv.js`: generated by `./bundle.sh`; never edit by hand. `index.html` loads the unbundled files in dev.

## Run
- Dev server: `python3 -m http.server 8000` (also configured as `landvoice-homepage` in `.claude/launch.json`).
- Rebuild the production bundle after any CSS/JS change: `./bundle.sh`, and commit `dist/` with the source change.

## Conventions (must follow)
- Every class starts with `lv-`, BEM style (`lv-block__element--modifier`).
- Use `var(--lv-...)` tokens; add new colours/sizes to `00-tokens.css`, don't hard-code them in section files.
- Light/dark is a band class (`lv-band--light` / `lv-band--dark`); text and line colours come from `--lv-fg`, `--lv-fg-muted`, `--lv-hairline`.
- JS hooks are `data-lv-*` attributes only, never IDs or classes.
- New section: add `assets/css/sections/<name>.css`, add a `<link>` in `index.html`, and bundle picks it up automatically via the glob.
- Respect `prefers-reduced-motion`; the page must still work without JS.
- Keep files small; add a new section file rather than growing `03-components.css`.
